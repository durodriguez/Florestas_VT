# Working in this repository

This repository is **one project: the UVM campus tree inventory and map.**
Read `README.md` for what it does and `docs/` for the data model, survey
process and deploy notes.

## Scope boundary

Only work discussed and created for the UVM Trees project belongs here.

If a task produces a file that is not part of the tree inventory — a document
for a different project, a scratch analysis, a prototype of something else —
**do not commit it here.** Ask the user which repository it should go in, or
whether to create a new one. Do not infer the destination from the fact that
this is the repository the session happens to have open.

The same applies when the session was started with a designated branch in this
repository. That designation says where *this project's* commits go. It does
not make this repository the default home for unrelated work.

A related project of the user's, with its own repository:
[BTV_Simulator](https://github.com/durodriguez/BTV_Simulator) — an educational
Burlington city-simulator game. It reuses this project's build architecture and
tree data, which makes it *adjacent*, not part of this repository.
