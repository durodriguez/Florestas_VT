Tree positions

How it works
  • Drag any dot onto the crown it belongs to. No need to select it first.
  • With a tree selected, the arrow keys nudge it 0.2 m (1 m with Shift).
  • Ctrl+Z (⌘Z) undoes the last move. Esc deselects.
  • Moved trees turn gold, with a line back to where the record had them.
  • Every move is kept in this browser as you go. When you are done, Export moves and send the file — npm run positions applies it. A move is not a survey visit, and the public map will not show it as one.
LiDAR crown peaks 0

Tops of tree crowns found in Vermont's statewide LiDAR, flown 21 April 2023 (leaf-off), across the whole campus boundary. A peak shows that a tree stood there, not which tree. Trees under about 3 m, crowns merged in a clump, and trees overhanging buildings give no peak. The layers button turns them off. Details: docs/LIDAR.md.

Tree crowns (SAL) 0

The Spatial Analysis Lab's LiDAR tree centroids, 2023: each crown's centre and its radius, drawn as a circle. Load the .zip as SAL sent it (or its .shp, .dbf and .prj together). Kept in this browser only — never uploaded or published. Only crowns on or near campus are kept.
