Image calibration

How it works
  • Add aerial images, each with its .geprint if it is a Google Earth print, and Align each one: click a feature on your image, then the same feature on the satellite map, four or more times. Two points place it; four or more correct its tilt.
  • The images and alignments are the same ones the positions tool uses: both pages keep them in this browser, so work done in either shows in the other after a reload. Alignment files from either page import into both.
  • Tick the images to work with, then Make image. One image ticked recompresses it onto the map's grid; several are merged into one. Where they overlap, the image with the lowest alignment error (1 in the list) wins.
  • Clip to keeps only what lies inside the campus boundary or one campus area. Detail sets the pixel size; finer is sharper and larger.
  • Made images are kept in this browser and listed under Made images. Export .zip saves the picture, a placement file this page can import again, and a world file (.wld, Web Mercator, EPSG:3857) for QGIS and other GIS programs.
  • Nothing is uploaded. Google Earth prints may not be published as a map layer, and neither may anything made from them; see docs/IMAGERY.md.
